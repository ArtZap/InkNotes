# InkNotes: состояние

Обновляется с каждой версией. На 15.11.2026.

Версия **0.38** в `main` (репозиторий ArtZap/InkNotes; версии 0.30–0.38 слиты по порядку, каждая — отдельный merge-коммит). Готово всё из MVP, v1.0 и v1.x, кроме пунктов, вынесенных в расширения ниже:

- 0.30–0.33: карточки для повторения, оглавление и ссылки, слои, вкладки, запись звука с привязкой к штрихам, формулы (вычисление, единицы, графики, печатный вид и LaTeX), окно увеличения, редактор фото и сканер, экспорт PDF/PNG и печать, транспортир, циркуль, таймер, сочетания клавиш;
- 0.34: PDF — выделение текста, ссылки, оглавление, поворот, поля, тёмный PDF;
- 0.35: надёжность по разбору кода, R8, lint и тесты на эмуляторе в CI;
- 0.36: две тетради рядом, быстрая заметка (плитка, виджет, экран блокировки);
- 0.37: синхронизация с Google Диском без сервисов Google (OAuth «Desktop app» через браузер, `drive.file`); приложение опубликовано в Google Cloud, страница и политика — artzap.github.io/InkNotes (ветка `gh-pages`); проверено на планшете;
- 0.38: холст — страница, растущая вправо и вниз (до 2 м).

**0.43 — в ветке `claude/v0.43-correct` (от 0.42), CI зелёный (обе проверки), не слита.** Окно «Как прочитано». Макет согласован с владельцем 15.11 (Design-холст «InkNotes — исправление формулы»).
- Касание серого ответа «?» или новой пунктирной метки «?» открывает окно. Метки ставятся там, где раньше было пусто: после «=» ничего не вышло, или у y = … / z = … не построился график («нет графика?»). У любого ответа в окне есть «Как прочитано…».
- В окне: рукопись с рамками символов (неуверенные — жёлтые пунктиром, касание выбирает символ), печатный вид, ответ, график или поверхность пересчитываются сразу. Ряд барабанов, по одному на символ, прокручивается вбок (просьба владельца). Под каждым барабаном место символа: индекс / строка / степень.
- Кандидаты символа: варианты ML Kit для всего прочтения, если число символов совпало; чтение символа отдельно; таблица похожих (1/l/I/7, 2/z, 0/o…). Знаки, найденные по форме (+, −, ·, °, ′), тоже на барабанах. Начальный выбор — то прочтение, которое взяла страница.
- «Готово» закрепляет текст формулы за её штрихами (`FixStore`, отпечаток по координатам). Страница читает закреплённое вместо распознанного, пока штрихи не изменятся. «Вернуть распознанное» снимает закрепление.
- «Нет нужного — набрать формулу» пока даёт ввод текстом (LaTeX-подобно). Калькулятор с шаблонами — 0.44.
- «Учиться моему почерку» (в окне и в настройках, по умолчанию включено): счётчики «прочитано X → выбрано Y» (`Learned`). Выбор, повторённый 2 раза, на барабане вторым. 3 раза и чаще, чем подтверждение, — так и читается: один символ подменяется, в длинном прочтении добавляется вариант. Только на устройстве; «Забыть мой почерк».
- Вопрос «Правильно прочитана формула?» внизу страницы, без всплывающего окна, только для формул, написанных сейчас. Настройки: только при сомнении (по умолчанию) / иногда (1 из 5 уверенных) / никогда.
- Модель (`Correct`) покрыта JVM-тестами (`CorrectTest`, `FixStoreTest`). Стенд CROHME без регрессии: метки «?» стенд не считает ответами.
- Проверить на планшете: окно на серых ответах и на метке; прокрутка барабанов (свайп и стрелки); место символа; набор текстом; «Готово» → ответ на странице меняется и остаётся после перезапуска; «Вернуть распознанное»; вопрос внизу; настройки.
- По скриншотам владельца (15.11, днём), исправлено:
  - «Готово» закрепляет то, что показано в окне, даже без изменений. Раньше неизменённое прочтение не закреплялось, и на странице оставалась своя ошибка.
  - ✕ под барабаном убирает символ (точку от i, прочитанную отдельно).
