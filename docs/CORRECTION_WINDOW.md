# Окно «Как прочитано» и калькулятор формул

Макет согласован с владельцем 15.11.2026. Макет лежит на Design-холсте claude.ai «InkNotes — исправление формулы» (у владельца, приватный). В нём четыре экрана:
- вход — где открывается окно, плюс настройки;
- барабаны;
- барабаны с графиком;
- калькулятор.

## Как попасть в окно (0.43)

- Касание серого ответа «?» (`PageAnswer.unsure`) или пунктирной метки «?» / «нет графика?» (`PageAnswer.missing`). Метка ставится, где раньше было пусто: после «=» ничего не вышло, или у y = … / z = … не построился график.
- Окно ответа → «Как прочитано…» — у любого ответа с `fix`. Касание ответа-ошибки открывает окно сразу.
- **Системы уравнений:** `Fix.system` — по `Fix` на уравнение. В окне барабаны всех уравнений подряд, под номерами; рукопись — все строки; «Получается» — уравнение на строку и ответ системы (`Correct.outcomeSystem`). Набор текстом — уравнение на строку. Закрепляется каждая сторона каждого уравнения; `solveSystem` берёт закреплённое вместо чтения.
- Вопрос внизу страницы «Правильно прочитана формула?».
  - Без всплывающего окна, писать не мешает.
  - Только для формул, написанных сейчас.
  - Режимы (`FixStore.Ask`): только при сомнении (по умолчанию), иногда — 1 из 5 уверенных, никогда.
- Нет: долгое нажатие на любую формулу и формулы, где ответ написан рукой, а не приложением. Можно добавить.

## Окно (0.43, `ui/FixDialog.kt`)

- Вверху «Было: …» — что показано на странице.
- **«Ваша запись»:** штрихи формулы, у символов рамки.
  - Неуверенные — жёлтым пунктиром, выбранный — акцентом, убранный — перечёркнут.
  - Касание символа выбирает его барабан.
- **«Получается»:** печатный вид (`FormulaArt`) и ответ, график (`MiniGraph`) или поверхность. Всё пересчитывается при каждом изменении (`Correct.outcome`).
- **Барабаны:** по одному на символ, в ряд; если не помещаются, ряд прокручивается вбок (просьба владельца). Каждый барабан:
  - список с привязкой (`rememberSnapFlingBehavior`), крутится плавно и встаёт на вариант; ▲▼ — шаг;
  - под ним место символа: □₂ индекс, □ строка, □² степень, ✕ — убрать (точка от i, случайный штрих).
- **Кандидаты символа** (`Correct.side`):
  - варианты ML Kit для всей «дыры», если число символов совпало;
  - чтение символа отдельно;
  - таблица похожих (1/l/I/7, 2/z, 0/o, 5/s, 6/b, 9/g/q, x/·, t/+…);
  - выученный выбор пользователя — вторым.
  - Если ML Kit прочитал «дыру» не по символам (sin из двух форм), то барабан один на всю «дыру».
- **Кнопки всегда видны внизу:**
  - «Нет нужного — набрать формулу» — в 0.43 ввод текстом, в 0.44 калькулятор;
  - галочка «Учиться моему почерку»;
  - «Вернуть распознанное» — если формула закреплена;
  - «Отмена»;
  - «Готово» — закрепляет **то, что показано**, даже без изменений.

## Учёба на почерке (0.43, `Learned`, `FixStore`)

- «Готово» записывает пары «что страница взяла → что выбрал пользователь», включая подтверждения (X → X).
- Выбор, повторённый 2 раза, на барабане стоит вторым.
- Выбор, повторённый 3 раза и чаще, чем подтверждение, сразу читается так при чтении страницы:
  - если в «дыре» один символ, он подменяется;
  - если символов больше, добавляется вариант после первого.
- Всё хранится только на устройстве. В настройках: выключить, «Забыть мой почерк» (закрепления остаются).
- Дальше (0.45): образцы символов пользователя как второй голос рядом с ML Kit, личные пороги раскладки.

## Калькулятор (0.44)

Открывается **вместо** барабанов («Нет нужного — набрать формулу») и сразу заполнен текущим прочтением. Требование владельца: **калькулятор должен покрывать абсолютно все формулы**. Пользователь не знает LaTeX и не может напечатать интеграл, поэтому всё делается кнопками-шаблонами.

- **Строка формулы:**
  - печатный вид, курсор;
  - пустые места □ (синие), ← → переходят между ними;
  - мелко LaTeX — для отладки и для знающих.
- **Вкладки шаблонов** (около 18 кнопок на вкладку, подпись под знаком):
  1. Структура — дробь, степень, индекс, индекс со степенью, √, ⁿ√, скобки ( ) [ ] { }, модуль, ⌊⌋, ⌈⌉, факториал, сочетания, система, «≔», штрих, перечисление.
  2. Анализ — ∫, ∫ₐᵇ, ∬, ∭, ∮, подстановка |ₐᵇ, d/dx, dⁿ/dxⁿ, ∂/∂, lim, односторонний lim, Σ, Π, ∞, →, ∇, Δ, dx.
  3. Функции — sin cos tg ctg arcsin arccos arctg arcctg sh ch th ln lg log□ eˣ sgn max min.
  4. Графики — y = □, f(x) = □, z = □, окно по x и по y, кусочная функция, f(□), f′(x), вторая функция, параметр, несколько графиков, ℝ.
  5. Буквы — латиница a–z, ⇧ заглавные.
  6. Греческие — все 24, ⇧ заглавные.
  7. Множества и логика — ∈ ∉ ⊂ ⊆ ∪ ∩ ∖ ∅ ℕ ℤ ℚ ℝ ℂ ∀ ∃ ¬ ∧ ∨.
  8. Векторы и матрицы — вектор, черта, крышка, точка, две точки, норма, ·, ×, ⟨,⟩, матрицы 2×2, 3×3, m×n, det, |·|, Aᵀ, A⁻¹, ∠, ⊥.
  9. Сравнения и знаки — ≠ ≈ ≡ ∼ ≤ ≥ < > ≪ ± ∓ ∝ ⇒ ⇔ ° % ∥ ….
  10. Единицы — м см мм км с ч кг г Н Дж Вт Па В А Ом Гц моль К.
- **Цифровой блок** справа: x y ( ) 0–9 , ÷ × − + = ← → ⌫ C.
- **Поиск символа по названию** («интеграл», «не равно», «тета», «ом») — по подписям всех вкладок.
- **Поле «Ввести LaTeX»** — для всего, чего нет на кнопках.
- **Внизу:**
  - ответ или график, пересчёт сразу;
  - «Отмена» — назад к барабанам;
  - «Готово» — закрепить.
- **Честно:**
  - что приложение не умеет посчитать, помечается «не умею считать такое»;
  - формула всё равно закрепляется: её видно, её можно экспортировать в LaTeX.
- **Реализация:**
  - модель «дерево с пустыми местами» на чистом Kotlin с тестами (ввод, курсор, ⌫ по структуре, вывод в текст для `Parser`);
  - UI на Compose;
  - то, что `Parser` пока не понимает (≠, ∈, матрицы…), — сначала проверить парсер и `Calc`, добавить по мере надобности.
