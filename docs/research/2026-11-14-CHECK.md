# InkNotes: проверка исследования от 14.11 и новые находки

Дата: 14.11.2026. Дополняет `RESEARCH_2026-11-14.md`, `ROADMAP_RESEARCH.md` и `PLAN_2026-11.md`. Здесь только то, что проверено поиском сегодня, и исправления. Всё, что касается красоты интерфейса, без скриншотов остаётся гипотезой.

## 1. Что подтвердилось

- **ML Kit Digital Ink.** Официальная документация описывает распознавание текста на 300+ языках и классификаторы фигур, эскизов и эмодзи. Математического классификатора в описании нет. Значит, символы формул ML Kit читает как обычный текст, по одному символу, и проверка «уровня 0» нужна обязательно. Модель около 20 МБ, работает офлайн.
- **MathWriting.** Лицензия CC BY-NC-SA 4.0 подтверждена. Человеческие штрихи записаны внутренними участниками Google на Android-приложении. Производные наборы (например, AmbHMEG на Hugging Face) прямо запрещают коммерческое использование. Вывод для нас: только тесты и бенчи, в APK ничего не попадает. Это уже решение владельца от 14.11.
- **Базовые цифры MathWriting.** CTC Transformer на 35 млн параметров: CER 5,56 % на тесте; Document AI OCR: 7,17 %. Совпадает с ROADMAP.
- **Apple Math Notes.** Рукописное число меняется прокруткой по шкале рядом с ним, результаты обновляются сразу. Функции из рукописи строят график. 3D-графики в iPadOS 26.

## 2. Исправления

- **Жест Apple.** В `ROADMAP_RESEARCH.md` написано «потянуть число». На деле это прокрутка по шкале рядом с числом. Формулировку пункта «бегунки переменных» поправить: у нас тоже шкала, а не перетаскивание.
- **CROHME: лицензия не подтверждена.** В документах написано «CROHME и MathWriting под CC BY-NC-SA». Для MathWriting это проверено. Для CROHME я нашёл только лицензию производного PNG-набора (Curtin University), а официальная страница CROHME23 на Zenodo в выдаче без условий. Перед тем как класть CROHME в бенч, открыть страницу CROHME23 и прочитать лицензию. Для тестов это не блокирует, для публикации не важно, пока данные не попадают в APK.
- **Бенч 2013 vs литература.** Наш 55,8 % верных (CROHME 2013, символы идеальные) и цифры литературы нельзя сравнивать напрямую: в литературе полный распознаватель с реальными символами, а у нас раскладка без ошибок чтения. Сравнивать можно только после уровня 0.

## 3. Новые находки

**Конкуренты на Android**
- **Mathpix Snip** (Android, версия 2.0): рукописный ввод с живой конвертацией формул, стирание зачёркиванием символа. По описанию распознавание идёт через их облако, но это надо проверить в политике конфиденциальности. Пункт про офлайн у нас сильнее: это аргумент в описании приложения.
- **MyScript Math** (Android, сборки 1.9.x, июль–октябрь 2026): переменные, несколько функций на одном графике, пошаговые решения, решение по фото, LaTeX, лассо. Модель: 7 дней бесплатно, дальше подписка или покупка. Почти всё уже есть у нас, кроме нескольких функций на одном графике (проверить по коду) и пошаговых решений по фото.

**Литература: что реально работает**
- **Образцы по метрике ExpRate на CROHME.** TAMER (ветка на основе дерева) даёт около 61 % на CROHME 2014/2016/2019. Uni-MuMER (дообученная VLM) в среднем 79,74 % по CROHME. Оба работают по картинкам штрихов, а не по онлайн-вводу. Для нашего онлайн-ввода их можно воспроизвести только растеризацией штрихов.
- **Структурный подход** (Seitz, Lengfeld, Timofte, 2025): система строит граф «штрих → символ → связь», даёт 74,14 % ExpRate на тесте CROHME 2023 и явно показывает, какой символ как связан. Это поддерживает идею из ROADMAP пункта 5 («разобрать формулу»): показывать пользователю граф распознавания как отладочный и объяснимый вид. Дёшево в реализации, полезно для тестов.
- **CROHME 2023** доступен на Zenodo в InkML, с онлайн-синтетикой в обучающей части. В бенч стоит добавить его, а не только 2014–2019.
- **Новые методы 2026**: диффузионный декодер на MathWriting и CROHME (arXiv 2602.03370); обучение с наградой по изображению (CVPR 2026, IMPO, +1,1 п.п. ExpRate). Для нас сейчас неприменимо: обучать модель мы не будем, пока не сделан уровень 0.

## 4. Что это меняет в плане

1. Уровень 0 (чтение символов ML Kit) остаётся первым. ML Kit формулы не поддерживает, поэтому его точность по классам определяет потолок всего конвейера.
2. Добавить в план небольшой пункт: **граф распознавания как режим отладки** (символы, связи, итоговое дерево). Он же помогает разбирать неверные ответы из «Неверно…».
3. Наборы для бенча: CROHME 2014/2016/2019 и 2023, MathWriting test. Перед добавлением CROHME прочитать лицензию (см. раздел 2).
4. Конкурентный анализ обновить: Mathpix и MyScript Math на Android — главные сравнения, Apple — ориентир по жестам.
5. Публикация по-прежнему блокирует только данные с некоммерческой лицензией; решение о своей модели остаётся отложенным.
