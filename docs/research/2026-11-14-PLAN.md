## Порядок работ

Версии делятся по тому, что проверяется на планшете (решение 14.11): измерения идут в CI и отдельной версии не требуют, а синхронизация — риск для данных и идёт отдельно.

**1. 0.41 → `main` одним релизом (нужен планшет).** Ветка 0.41 содержит 0.39 и 0.40. Проверить: запись при выключенном экране и убийство процесса; быстрая заметка на заблокированном экране; две половины и вкладки; удаление папки InkNotes на Диске; выход и вход в Google; смена языка с открытыми тетрадями (ничего не теряется); язык рукописи отдельно; формулы «2¹⁰ =», «8.5 + 1 =», «∛8 =». Затем один PR в `main`.

**2. 0.42 — формулы целиком: сначала измерить, потом чинить по данным.**
1. Парное сравнение: бенч хранит исход каждой формулы, регрессия — по переходам «верно → неверно», а не по процентам.
2. Кривая «риск — покрытие» и точка «неверных ≤ 2 %».
3. Метаморфические тесты и «граница решения» на JVM, в CI.
4. Уровень 0: ML Kit на символах CROHME на эмуляторе (точность, путаницы, полнота вариантов), отдельный workflow по кнопке.
5. Условия CROHME 2014–2023 — прочитать; если подходят для тестов — подключить как отложенную проверку.
6. Исправления по этим данным: индексы, дроби с вложениями, «под вопросом» для уравнений и определений, личная матрица путаниц, граф распознавания для отладки.

**Итог 0.42 и что дальше по формулам.** Измерение показало: с настоящим ML Kit неверна треть уверенно показанных ответов на «выражение =» и больше половины на формулах из букв; раскладка — уже меньшая часть беды. Дешёвые сигналы сомнения исчерпаны (сдвиги порогов, согласие двух прочтений ML Kit). Следующий шаг по формулам — не новые пороги, а чтение символов: (а) выбор варианта по контексту и по смыслу формулы (ML Kit даёт верный символ среди вариантов в 96 %); (б) свой маленький классификатор символов на разрешённых данных или собственных образцах — решать по стенду на устройстве, который теперь есть. Стенд CROHME 2012 показывает подозрительно много неверных (73 %) — сначала проверить, не артефакт ли разметки.

**Предложение владельца (14.11, вечер): учиться на почерке пользователя.** Когда ответ под вопросом или помечен «Неверно…», предлагать варианты прочтения — выбрать или ввести формулу вручную; изредка ненавязчиво показывать, как прочитано. Исправления — данные самого пользователя (лицензионно чисты, на устройстве): (1) выбранное прочтение закрепляется за штрихами; (2) личная матрица замен (у этого человека l — это 1) пересортировывает варианты ML Kit — верный есть среди них в 96 %; (3) личные образцы символов — «второй голос» ближайшего соседа к ML Kit; (4) личные пороги раскладки (как высоко он пишет степени). ML Kit сам не дообучается — «дообучение» = пересортировка и второй голос. Предложено сделать это 0.43 (формулы), WebDAV — следом. Ждёт решения.

**3. 0.43 — WebDAV (Яндекс Диск, Nextcloud) отдельно.** Затем функции этапа 3 пачками по 2–3 в версию: экспорт в Markdown/Obsidian, выравнивание почерка, шкала переменных (как у Apple), несколько функций на одном графике, предпросмотр кисти, тактильный отклик; позже ответ почерком, расшифровка лекций, орфография рукописи.
